# speakjoy.co

The front page — what speakjoy is, on the web and on iPhone.

Static, no build step. GitHub Pages serves `index.html` from `main`, and `CNAME`
points it at **speakjoy.co**.

The journal itself lives elsewhere:

| | |
|---|---|
| `speakjoy-web` | the web journal, at **speakjoy.app** |
| `speakjoy-ios` | the iPhone app |

`logo.svg` is copied from the app so the mark is the same drawing in both
places. If it changes there, copy it here.
